# Dados sintéticos de teste

`fixtures.py` gera exclusivamente documentos sintéticos para testes automatizados. Os adversários, identificadores, números, datas e fonte gerados não descrevem partidas reais. O recorte de negócio permanece o do Flamengo, para exercitar a regra correta, e a origem usa o namespace `synthetic` e o domínio reservado `.invalid`.

Esses documentos não são dados Bronze, Silver ou Gold, não homologam fonte e não podem ser apresentados como estatísticas. Nenhum jogador ou resultado esportivo é gerado. O caso de evidência de aprovação também é sintético e verifica apenas a consistência estrutural da declaração.
